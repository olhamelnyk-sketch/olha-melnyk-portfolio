# Olha Melnyk — Portfolio

Personal portfolio of Olha Melnyk, Junior UX/UI Designer (Tallinn, Estonia).

Built with [Astro](https://astro.build), deployed on [Vercel](https://vercel.com).

## Structure

- `src/pages/` — pages (`index.astro` is the home page)
- `src/components/` — sections of the page (Header, Hero, …)
- `src/styles/global.css` — colours (light / dark themes), fonts, base styles
- `docs/` — site plan
- `design/` — mockup exports from Figma

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:4321.

## Build

```bash
npm run build
```
